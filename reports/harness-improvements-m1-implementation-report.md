## What the milestone changed

Six structural gaps from the deep analysis, plus two operator-directed additions:

1. **The framework runs under its own payload.** `tools/self-harness.mjs` syncs `template/.claude/` to the repo root and gates drift with `--check`. PHE now eats its own harness.
2. **The stop gate guards its own config.** A GREEN whose `stopGate` list shrank — or whose `harness.json` was deleted — since the last RED is refused. Editing the gate was the cheapest remaining way to "go green".
3. **Contract claims come from raw text.** A summarized doc fetch invented a hook field name (`start_reason`); the research path now greps the raw markdown page or marks the claim `unverified (summary only)`.
4. **The handoff trigger is a number.** `~120k tokens` off the statusline `ctx` segment, which now prints absolute tokens beside the percentage; compaction re-invokes the stage skill.
5. **Gate output stays on disk.** `.claude/tooling/run-check.mjs` writes the full log to `.claude/state/checks/<label>.log` and puts one `exit=` header plus a bounded tail in the window.
6. **`/evolve` gates the push.** `requireEvolveBeforePush` defaults on; `guard.mjs` denies `git push` until the marker is newer than HEAD.
7. **Platform drift corrected.** `CLAUDE_CODE_SUBAGENT_MODEL` is a default since 2.1.251, not an override; `_FORCE` (2.1.257) defeats the reviewer's pin and now warns at session start; `maxTurns` is enforced on every version, with 2.1.246 as the partial-marker floor.
8. **Model roles.** A fourth role `routine` for Sonnet-grade work; `build` is opus and never sonnet; the reviewer is always a fresh `deep` context.
