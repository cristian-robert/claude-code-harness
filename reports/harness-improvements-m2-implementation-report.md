## What the milestone changed

Seven Tier 2 items of the deep analysis, and six defect classes the M1 reviews deferred.

**Tier 2**

1. **Plans cite by phrase, and a tool checks the citation.** `template/.claude/tooling/plan-anchors.mjs` reads a plan's `## Context` section, resolves each `` `path` · "phrase" `` anchor against the working tree, and exits 1 on any `MISS`. A citation group holding a backticked path-like token that parses to no anchor prints `UNPARSED`; a plan with no `## Context` section exits 1 instead of reporting a vacuous pass. `/plan-work` runs it before handing off, `/implement` before building.
2. **Plan confidence is mechanical, not felt.** `confidence` is capped at 6 unless every `Read first:` file was read this session and `plan-anchors.mjs` exits 0, every external tool is cached or freshly researched, and open questions are zero. Below 7 the planner must state what would raise it and ask.
3. **Evidence comes from the consumer, and unasked decisions are declared.** `00-core.md:35` now requires output from the consumer of the change — the hook fed its stdin JSON, the CLI, the test that reads the config — never a read-back of the file that declares it. `/implement`'s report contract gains a `Decisions taken unasked` row: numbered, each with its cost if wrong, or "none".
4. **`/evolve` reads the platform's own measurements and the auto-memory delta.** The skill asks the operator for `/skill-doctor`, `/doctor` and `/context` (interactive commands it cannot run; absent → `not measured`, never a guess), and runs `memory-delta.mjs diff` so a `feedback` line saved to machine-local memory becomes a team rule instead of staying private. The marker step snapshots the memory file so the next run has a baseline.
5. **Review follow-ups M3 and M6 are closed.** M3: the tracking-root resolution is stated once, in `work-tracking.md` "The tracking root"; six skill restatements became cites. M6: `guard.mjs` denies a `Write` of `plans/*-plan.md` whose `Knowledge to load first:` line is missing or empty — the field ADR-014 created and nothing checked.
6. **The ledger measures skill bodies and docs, and the root gate enforces both.** `tools/context-ledger.mjs` gained a skill-bodies table in est. tokens (soft warn 4000, hard 5000 — the platform's per-skill re-attach cap) and a `--docs <dir>` table (hard violation above 130 lines, and a missing directory is a violation, never a silent pass). `docs/01`, `docs/03` and `docs/99` were trimmed to fit. The command joined the root `stopGate`, so the docs budget is measured on every turn end instead of being a guideline nobody ran.
7. **Migrations are CLI code, never skill prose.** A retired or renamed key, skill or path is `cli/migrations.js` (`RENAMED_SKILLS`) or `cli/harness-config.js` (`RETIRED_KEYS`), pinned by a test and applied on `init`/`update`. A skill may call a subcommand or catch a hand-copied survivor; it never carries the logic, because prose cannot be verified headlessly.

**Defect classes**

8. **The stop gate ignores what it cannot run, and arms both layers on INCOMPLETE.** A `stopGate` entry that is not a non-empty string is filtered before `execSync` — a typo'd number used to throw and pin the gate RED for the whole session — and the session-start banner and statusline now count only the entries that run. An INCOMPLETE verdict arms the opt-in gated-file snapshot as well as the gate-config snapshot. The INCOMPLETE message no longer invites the edit the gate refuses.
9. **`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` follows the documented on/off rule and survives compaction.** `0` and `false` are off (the variable is absent from the platform page's set-at-all list, read raw 2026-09-05); the warning is emitted before the compaction branch exits, so it fires after a compaction too. The statusline gained a megatoken step: a 1M window reads `1.0M`, not `1000k`.
10. **`run-check` fails closed.** Any unconsumed word before `--` — an unknown flag, a flag without a value, a stray positional — is a usage error at exit 64 instead of a silent default. Multi-word arguments survive the shell round-trip, the tail is bounded, the log root resolves to the repo root rather than the cwd, and the state directory prunes to 20 labels.
11. **The push-gate wording matches the code.** Every "default true" / "default on" claim about the evolve→push gate became "on in the shipped config; an absent key is off" across `template/`, `docs/`, `README.md` and both `harness.json` `$comment`s. `tools/ratchet-greps.mjs` gained three retirement entries — this wording, "make the checks faster" and "never builds" — so the retired phrasing cannot come back unnoticed.
12. **The root harness sweeps by effect, and says what it does not have.** `tools/self-harness.mjs` no longer derives its extras sweep from the template's own directory list, so a retired top-level directory is swept; it is excluded from the npm tarball; the two adapted root knowledge skills point at the vault; and session-start reports an absent `knowledge-base/` honestly instead of implying one exists. A blank Codex role now throws at emit instead of silently defaulting.
